# Проверка Yogurt с подписочными CLI

Дата: 15 ноября 2026 года.

## Версии и объём изменений

- Исходный Yogurt: [`a7596ec6471763ea059effed8be1ad7d8efd5959`](https://github.com/FrigadeHQ/yogurt/commit/a7596ec6471763ea059effed8be1ad7d8efd5959), версия 0.3.21.
- Контракт Porch: [`b0c5cf4d5d236677595a508ee3491d56ae1e0e8a`](https://github.com/CodeAlive-AI/pragmatic-orchestration/commit/b0c5cf4d5d236677595a508ee3491d56ae1e0e8a).
- Проверенный код этого форка: `1f01bfe`. Следующий коммит добавляет только документацию.
- Ветка: `feat/subscription-harness`.

По умолчанию расшифровка и текстовые функции используют agy, `gemini-3.8-flash`, `medium`. Альтернативы — точные профили Porch и исходный локальный режим. Модель для аудио в Porch задаётся отдельно от текстового профиля. Ключи API и учётные данные не сохраняются в настройках Yogurt.

## Выполненные проверки

Все команды ниже выполнялись из каталога `app`. Для временных файлов был задан доступный каталог через `TMPDIR`.

| Проверка | Результат |
| --- | --- |
| `node_modules/.bin/tsc -p . --noEmit` | Успешно |
| `node_modules/.bin/electron-vite build` | Успешно: main, preload и renderer |
| Полный `node_modules/.bin/vitest run` | 2222 теста: 2205 прошли, 2 завершились ошибкой среды, 15 пропущены |
| Тесты адаптеров `test/harness.test.ts` внутри полного запуска | Все 55 прошли |
| `git diff --check` относительно исходного коммита | Успешно |

Полный запуск Vitest завершился с кодом 1 из-за двух тестов `test/mcp.test.ts`: запуск MCP-сокета и замена сокета после сбоя. В обоих случаях `listen` возвращает `EPERM: operation not permitted` при создании Unix-сокета. Эти же две ошибки наблюдались до интеграции новых адаптеров. Тесты и ограничения среды не отключались. Изменений в реализации MCP-сокета этот форк не вносит.

## Что покрывают проверки

- Передача настоящего PCM WAV 16 кГц, включая заголовок и байты аудио; модель Flash и уровень medium передаются явно.
- Нативный WAV через Porch сохраняет точную длительность 2.000 секунды; схема JSON и русский язык передаются в тот же запрос. ffmpeg и ffprobe для этого пути не требуются.
- Профиль Porch должен присутствовать в машинном списке возможностей транскрипции. Имя профиля само по себе не считается доказательством поддержки аудио.
- Финальный результат agy проверяется по статусу и структуре. Промежуточные фрагменты и сообщения об ошибках не подставляются вместо ответа.
- Пустой список сегментов означает тишину; пустой ответ, ошибка чтения аудио, нечисловые или выходящие за длительность таймкоды означают неудачу запроса.
- Сохранение смещения аудиофрагментов относительно встречи, раздельных дорожек и русских имён; язык остановленной встречи не меняется вслед за новой записью.
- Тайм-ауты, отмена, завершение дочерних процессов, ограничение объёма вывода, очистка временных файлов и повторная попытка после установки отсутствовавшего CLI.
- Переполнение очереди оставляет расшифровку незавершённой и сохраняет аудио для восстановления.
- Длинная русская речь, кавычки, переносы строк и Unicode корректно учитываются при разбиении по контексту.
- Полный цикл русских промежуточных конспектов, финального конспекта, следующих шагов и заголовка проверяется с тестовым agy при бюджете 16384. При бюджете 8192 проверяется сохранение готового конспекта, когда дополнительный запрос уже не помещается, и заголовок по полному конспекту.
- Сохранённые и активные настройки различаются до перезапуска. Переменные окружения показаны явно и не вызывают бесконечное предложение перезапуститься.
- Подписочный запуск не вызывает загрузки локальных моделей и проверки оборудования. Режим языка речи «Русский» сохраняется; русские запросы задач, решений и дат распознаются.

## Что не проверялось в этой среде

- Живой вход в agy, реальная транскрипция Gemini, её точность, задержка, квоты и совместимость конкретного аккаунта.
- Работа микрофона, системного аудио и разрешений ОС в запущенном приложении.
- Electron E2E-сценарии. Сценарии настроек провайдера и языка речи добавлены, но здесь не запускались.
- Нативная сборка записывающих помощников, подписанные установщики и запуск на macOS или Windows. Проверенная сборка `electron-vite` не является готовым DMG, EXE или AppImage.

Автоматизированные тесты запускают подставные исполняемые файлы с контролируемыми ответами. Они проверяют протокол и поведение приложения, но не измеряют качество модели. Прямой agy использует настройки сессии для выбора провайдера аккаунта; слияние этих настроек в живой версии CLI здесь не подтверждалось.

Porch сохраняет авторизацию и разрешения выбранных профилей. Его внутренний runner проверен по указанному коммиту; будущая несовместимость требует обновления адаптера. Поиск по библиотеке в режиме провайдера использует слова и выбранные встречи без локальных embeddings.

Настройка, ограничения тарифов провайдера и команды запуска описаны в [русской инструкции](subscription-harness.md).
